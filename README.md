# DRIVETONE — Android

Mobil odaklı araç ses kontrol uygulaması. Bu depo Android Studio projesini ve GitHub Actions üzerinden debug APK derleme akışını içerir.

## Kapsam

- Android telefon ses seviyesini yönetme ve aktif medya oturumunu izleme (bildirim erişimi verilirse)
- Dahili müzik oynatıcıda 28 bant EQ, ses profilleri ve spektrum analizi
- Gerçek teybin FOR-X DSP kontrol protokolü henüz doğrulanmadı. Spotify/YouTube sesine doğrudan EQ uygulanmaz.

`Actions` bölümündeki **Build DRIVETONE APK** işlemi başarılı olursa `DRIVETONE-debug-apk` artefaktı indirilebilir.
